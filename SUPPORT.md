# Support

## Questions and usage help

Open a GitHub Discussion when available, or a GitHub issue with a minimal
public reproduction. This project is maintained on a best-effort basis and
does not provide private consulting or guaranteed response times.

## Bugs

Use the issue tracker for deterministic false positives, missed package
failures, crashes, and documentation problems. Include exact toolchain versions
and a tarball-safe reproduction whenever possible.

## Security

Do not open a public issue for a vulnerability. Follow
[SECURITY.md](./SECURITY.md).

## Supported versions

Before the first stable release, only the latest published prerelease is
supported. After v1, the latest major release receives fixes. Older majors may
receive critical security fixes at the maintainer's discretion.
