# Diagnostic reference

Diagnostic codes are append-only. A code keeps the same meaning across
compatible releases and is never reassigned.

- [PC1000](PC1000.md): consumer installation failed
- [PC1001](PC1001.md): package evaluation failed
- [PC1002](PC1002.md): TypeScript consumer compilation failed
- [PC1003](PC1003.md): package encapsulation failed
- [PC1004](PC1004.md): package executable failed
