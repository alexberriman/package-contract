# PC1003: Package encapsulation failed

A direct import of a packed private JavaScript file succeeded even though the
package declares an `exports` boundary and does not expose that file path.

This probe is conservative. It runs only when a packed JavaScript file can be
identified whose direct subpath is not matched by the export map. A failure
other than Node.js `ERR_PACKAGE_PATH_NOT_EXPORTED` is `not-evaluated`, because it
does not prove encapsulation.
