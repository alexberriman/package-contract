# PC1001: Package evaluation failed

Node.js could resolve neither the package entrypoint nor its dependencies, or
the package threw while being evaluated in an isolated consumer.

The diagnostic is emitted only for a module system and subpath the package
claims to support. Its evidence is the bounded, normalized output from the real
Node.js process. Failures that Publint or Are the Types Wrong causally explain
are hidden by default and remain available with `--include-explained`.
